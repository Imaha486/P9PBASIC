# MA2026A.D88 解析メモ（P8PBASIC 設計資料）

作成: 2026-11-17 / 対象ディスク: `MA2026A.D88`（Music Arena 2026, ディスクA）

P8PBASIC の目標は、このディスクが P88SR + PC88.ROM なしで動くこと。
そのためにまずディスクの実物を解析した結果をここに固定する。
推測と実測は区別して書く。

## 1. ディスク形式（実測）

PC-88 N88 Disk BASIC 形式（2D）。

| 項目 | 値 |
|---|---|
| D88 メディア種別 | 0x00（2D） |
| ジオメトリ | 40 シリンダ × 2 ヘッド × 16 セクタ × 256 バイト = 327,680 バイト |
| ディレクトリ | C18 H1 R1、16 バイトエントリ `[名前6][拡張子3][属性1][開始クラスタ1][0xFF×5]` |
| FAT | C18 H1 R14/R15/R16 に同一コピー 3 部（各 256 バイト） |
| FAT 意味 | 0x00–0x9F=次クラスタ、0xC1–0xDA=最終（下位5ビット=使用セクタ数）、0xFE=予約、0xFF=空き |
| クラスタ | 8 セクタ = 2,048 バイト、ディスク先頭からのセクタ通し番号で数える |
| 削除ファイル | 先頭バイト 0x00（旧版の MA2026.TXT / README.TXT の残骸が複数残っている） |

抽出ツールは本解析のために新規作成した（PC-98 用の既存抽出器は 2HD 専用で流用不可）。

## 2. ファイル目録（実測）

| ファイル | 属性 | クラスタ | サイズ | 正体 |
|---|---|---|---|---|
| MENU.ALP | 0x80 | 76–77 | 3,840 B | トークン化 BASIC（本体プログラム。行番号 100〜） |
| menu | 0x80 | 78–81 | 8,192 B | トークン化 BASIC（行番号 1000〜。`MA2026` 参照と自己 SAVE を含む） |
| NEOMSC | 0x01 | 82–84 | 4,352 B | Z80 機械語（属性 0x01 = 機械語ファイル） |
| MA2026.TXT | 0x00 | 85–91 | 12,800 B | Shift_JIS テキスト（曲目・クレジット類） |
| README.TXT | 0x00 | 92–98 | 14,080 B | Shift_JIS テキスト |

クラスタ 0–75 は FAT 上すべて予約（0xFE）。ここに IPL、直接セクタ読み
される PMD の MML データ／ADPCM データ等が入っているとみられる
（トラック 1 付近に `ADPCM DATA for PMD ver.4.4-` の文字列を確認）。
予約領域の内部構造は未解析。

## 3. プログラムから読み取れたこと（実測＋一部推測）

- MENU.ALP の冒頭は `save "1:MENU  ALP"` を含む行で始まる（自己保存の常套）。
- `BLOAD "NEOMSC",R` と読める箇所があり、NEOMSC を読み込んで実行する。
- 文字列として `"MEGAFEPPS MUSIC ARENA 2026 [ARCADE SPECIAL PART2]"`、
  `"P.M.D. v3.3 system loading..."`、`IF SB=1 THEN BLOAD"pmd",&HAA00`、
  `RBYTE ...`（PMD 関連）、`PCM DATA LOAD` / `MML LOAD skip!` 等が
  ディスク内に確認できる。つまり演奏は PMD 系ドライバが担い、
  BASIC はメニュー表示・曲選択・データロードの制御側。
- DATA 文に曲目リスト（タイトル、作者、パート数など）がある。

## 4. 未解明（今後の作業）

1. **PC-88 トークン形式**: PC-98（N88-BASIC(86)）版とはコード表が異なる。
   既存の 86 用デトークナイザはそのままでは使えない（先頭行しか読めない）。
   仮説段階の対応: 0xD4 = BLOAD、0x91 = PRINT と読める箇所があるが未検証。
   実物と突き合わせてコード表を実証する必要がある。
2. **起動フロー**: IPL → Disk BASIC → どのファイルが自動実行されるか
   （MENU.ALP と menu の役割分担を含む）。
3. **予約領域（クラスタ 0–75）の構造**: PMD のデータ配置、PCM データの
   読み出し方法（BASIC のどの命令で読むか）。
4. **NEOMSC の役割**: PMD 本体なのか、独自ドライバなのか。
   Z80 機械語なので、P8PBASIC 側でどう扱うか（エミュレーション要否）
   が設計上の最大の論点。
5. **P.M.D. の版と配置**: `pmd` ファイルはディレクトリに無い。
   予約領域に含まれているか、NEOMSC に含まれているかを確認する。

## 6. 実装方針（案）

- 土台は P9PBASIC のインタプリタ本体（評価器・文実行・変数・数値）。
  PC-98 固有 HAL（hal98.c）は PC-88 の画面・キー・サウンドへ置換する。
- ディスクは PC-88 Disk BASIC 形式（本書 §1）を直接読む。
- 必要な BASIC 命令の範囲は、デトークナイズが完了してから確定させる。
  先に全部入りを目指さない。
