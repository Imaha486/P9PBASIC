# ホスト版 CLI（Mac / Linux ヘッドレス）

作成: 2026-11-17

P8PBASIC の最初の動作形態は、MacBook Pro の CLI でヘッドレスに動く
コマンドラインツールとする。

## なぜ CLI からか

- P9PBASIC のソースには最初からホスト用 HAL（`src/halhost.c`）があり、
  インタプリタ本体とハードウェア層が `src/hal.h` で分離されている。
  そのためホスト版は新規開発なしに近い形でビルドできた（下記実測）。
- MA2026 対応の本当の山は画面ではなく、PC-88 トークン形式の解読と
  プログラムの実行互換。CLI はその検証台（キー入力スクリプト、画面
  ダンプ、グラフィックの PPM 出力）として使える。
- GUI（P9PBASIC と同じ画面エディタのインターフェース）は、同じ
  `hal.h` の上にウィンドウ用 HAL を書けば後から足せる。順序としては
  CLI で互換を固めてからが合理的。

## ビルドと実行（実測済み）

```sh
./build-host.sh          # build-host/p8pbasic ができる
cd build-host
cp ../samples/HELLO.BAS .
P9PKEYS='Taro\r' ./p8pbasic HELLO
```

- 2026-11-17、MacBook Pro（clang）と Linux（gcc）の両方でビルド成功。
  変更は `-lm` の追加のみで、ソース無改造。
- `HELLO.BAS` が最後まで実行でき、INPUT への応答（キー入力スクリプト）
  と画面ダンプ（stdout、Shift_JIS）を確認済み。

## ホスト HAL の仕様（halhost.c）

| 環境変数 | 意味 |
|---|---|
| `P9PKEYS` | キー入力スクリプト。`\r`=RETURN、`\e`=ESC、`\1`〜`\0`=F1〜F10 等 |
| `P9PGFX` | 指定すると終了時にグラフィック画面を PPM（640×400）で書き出す |

- 終了時にテキスト画面（80×25）を stdout へダンプする。
- キーが尽きた状態でアイドルが続くと自動終了する（テスト用）。
- 環境変数名の `P9P` 接頭辞は P9PBASIC 由来。P8 側の改名は互換作業と
  一緒に行う（現時点では実害がないので据え置き）。

## 現時点の制限

- これはまだ P9PBASIC のインタプリタそのもの（PC-98 の N88-BASIC(86)
  方言）であり、PC-88 方言・PC-88 ディスク形式には未対応。
- サウンド（FM/SSG/リズム音）はホスト HAL では無音。
  MA2026 の演奏系は、ドライバ扱い（NEOMSC / PMD）の設計が決まってから。
