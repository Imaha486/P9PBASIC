# P9PBASIC マニュアル（Version 1.00）

> **P9PBASIC は、PC-98 の BIOS ROM の逆アセンブルや、N88日本語BASIC(86) のコード盗用は一切行っていません。**
> **すべて C 言語で新規に書いたプログラムです。そのため、実機の BIOS ROM が無くても EXE ひとつだけで動作します。**
>
> P9PBASIC は画面・キーボード・グラフィック・ビープを BIOS を一度も呼ばずに I/O ポートと VRAM で直接操作します。
> 必要なのは MS-DOS のファンクションコール（INT 21h：ファイル・メモリ・時計）だけなので、
> BIOS ROM を持たないエミュレータでも、MS-DOS の機能さえあれば動きます。

P9PBASIC は、PC-9801 上の MS-DOS で動く **N88日本語BASIC(86) 互換の BASIC インタプリタ**です。
単一の実行ファイル `P9PBASIC.EXE` だけで動き、画面・キーボード・グラフィック・ビープは
**内蔵 BIOS を呼ばずに I/O ポートと VRAM を直接操作**します。
MS-DOS（INT 21h）を使うのは、ファイル操作・割り込みベクタの登録・メモリ確保・日付と時刻だけです。

---

## 第一章 基本的な使い方

### 1. 起動方法

```
P9PBASIC                 … エディトモードで起動（Ok が出て直接コーディングできます）
P9PBASIC GAME            … GAME.BAS を読み込んで即実行（拡張子 .BAS は省略可）
P9PBASIC GAME.BAS /K     … 実行後もエディトモードに残る
P9PBASIC GAME /R         … INP(&H41) を実ポート直読みにする（第三章参照）
P9PBASIC GAME /G         … グラフィックキャラクタモード（下記）
```

- `/G` を付けると、80h〜9Fh・E0h〜FFh を漢字の 1 バイト目として扱わず、半角のグラフィック文字として表示します。
  PC-8801 用のプログラムで罫線などのグラフィック文字が漢字に化けるときに使います
  （PC-98 の半角グラフィック文字として表示されるため、PC-8801 と同じ形になるとは限りません）。
  `/G` が無いときは N88日本語BASIC(86) と同じく漢字として扱い、漢字として成り立たない組み合わせは 1 バイト文字として表示します。

- ファイルを指定して起動した場合、プログラムが `END` または最終行まで実行されると、自動的に MS-DOS に戻ります。
- 実行中にエラーが出たり STOP キーで中断したりした場合は、エディトモード（Ok）に移るので、そのまま修正できます。
- エディトモードから MS-DOS に戻るには `SYSTEM` と入力します。

PC98PLAYER で使う場合は、設定 INI の「最初に実行するプログラム」に
`P9PBASIC.EXE`（ソースを直接実行するなら `P9PBASIC.EXE GAME.BAS`）を指定してください。

### 2. エディトモード（スクリーンエディタ）

N88-BASIC と同じく、**画面上の好きな行にカーソルを合わせて RETURN を押すと、その行が取り込まれます**。

| キー | 動作 |
|---|---|
| ↑ ↓ ← → | カーソル移動 |
| RETURN | カーソルのある論理行（折り返した行も含む）を取り込む |
| BS | カーソルの左の文字を消す |
| DEL | カーソル位置の文字を消す |
| INS | 挿入モードの切替（カーソルが半分の高さになります） |
| HOME | カーソルを左上へ |
| SHIFT+HOME (CLR) | 画面消去 |
| CTRL+E | カーソルから行末まで消す |
| STOP / CTRL+C | 入力の取り消し・実行の中断 |
| f1〜f10 | ファンクションキー文字列の入力（`KEY` で変更可）。初期値は f1 `list `、f2 `run`＋RETURN、f3 `load "`、f4 `save "`、f5 `cont`＋RETURN、f6 `files`＋RETURN、f7 `auto `、f8 `renum `、f9 `key `、f10 `screen ` |

- 行番号付きで入力するとプログラムに登録され、行番号だけを入力するとその行が削除されます。
- `AUTO` で行番号の自動発生、`RENUM` で付け直し、`DELETE` で範囲削除、`EDIT 行番号` で行の呼び出しができます。
- `LIST`、`RUN`、`CONT`、`NEW`、`LOAD "名前"`、`SAVE "名前"`、`FILES`、`KILL`、`NAME` が使えます。

### 3. プログラムファイル

- `SAVE` は常に **ASCII 形式（テキスト、改行 CR+LF、末尾 ^Z）** で保存します。
- `LOAD` / 起動時の引数で読めるのも ASCII 形式です。
  N88-BASIC の中間言語形式（先頭が FFh のファイル）は読めないので、「ファイルのモードが正しくありません」（エラー番号 54）になります。
  元の環境で `SAVE "名前",A` として保存し直したファイルを使ってください。
- Windows のテキストエディタで書いたソースも、文字コードが **Shift_JIS** なら読めます。

## 第二章 対応している命令・関数

### 制御・プログラム管理
`END` `STOP` `CONT` `RUN` `GOTO` `GOSUB` `RETURN [行]` `IF〜THEN〜ELSE`（`IF〜GOTO` も可）
`FOR〜TO〜STEP〜NEXT`（`NEXT I,J` 形式も可）`WHILE〜WEND` `ON〜GOTO/GOSUB`
`ON ERROR GOTO` `RESUME [0|NEXT|行]` `ERROR` `ON KEY GOSUB` `KEY(n) ON/OFF/STOP`
`LIST` `NEW` `AUTO` `RENUM` `DELETE` `EDIT` `TRON` `TROFF` `CLEAR` `SYSTEM`
`LOAD` `SAVE` `MERGE` `CHAIN` `REM` `'`

**ラベル**：行の先頭に `*名前` と書くと、その行をラベルで指定できます。
`GOTO` `GOSUB` `THEN` `ELSE` `ON〜GOTO/GOSUB` `ON ERROR GOTO` `ON KEY GOSUB` `RESTORE` `RESUME` `RETURN` で、行番号の代わりに使えます。
名前には英字・数字・ピリオドが使え、大文字と小文字は区別しません。
```
10 GOSUB *INIT
20 *MAIN '--- メインループ
30 IF INKEY$="" THEN GOTO *MAIN ELSE END
100 *INIT:CLS:RETURN
```
ラベルが見つからないときは「その行番号はありません」（エラー番号 8）になります。`RENUM` してもラベルはそのまま使えます。

### 変数・データ
`LET` `DIM` `ERASE` `SWAP` `READ` `DATA` `RESTORE [行]` `DEF FN` `DEFINT/DEFSNG/DEFDBL/DEFSTR`
`OPTION BASE` `RANDOMIZE` `MID$(A$,n,m)=` `LSET` `RSET` `TIME$=` `DATE$=`

- 変数名は 40 文字まで有効、型宣言文字 `% ! # $` に対応します。
- 整数は 16 ビット、単精度は 7 桁表示、倍精度は 16 桁表示です。
- 配列は宣言なしで使うと要素 10 まで自動で確保されます。

### 入出力（画面）
`PRINT`（`?` も可）`PRINT USING` `INPUT` `LINE INPUT` `WRITE` `LOCATE` `CLS [0〜3]`
`COLOR` `WIDTH 80/40` `CONSOLE 開始行,行数,ファンクションキー表示,カラー/モノクロ` `KEY n,"文字列"` `KEY ON/OFF/LIST` `BEEP [0|1]` `SOUND`

- `CONSOLE` の 4 番目を 0 にするとモノクロモードになり、`COLOR` の値が文字の属性になります（bit0 シークレット、bit1 ブリンク、bit2 反転、bit3 アンダーライン。例：`COLOR 4` で反転表示）。1 でカラーモードに戻ります。
- `PRINT` の制御コード（CHR$(7) ベル、8 BS、9 TAB、11 HOME、12 画面消去、13 改行、28〜31 カーソル移動）を解釈します。
- エスケープシーケンスは `ESC*`（画面消去）、`ESC[y;xH`、`ESC[nA/B/C/D`、`ESC[2J`、`ESC[K`、`ESC[…m`（色・反転）、`ESC[>1h/l`（ファンクションキー表示の消去・表示）に対応します。
- Shift_JIS の漢字は、テキスト VRAM に JIS コードで書き込んで表示します（漢字 ROM を使う表示はハードウェア任せです）。

### グラフィック（640×400、16色）
`SCREEN モード,スイッチ,アクティブページ,表示ページ` `PSET` `PRESET` `LINE (…)-(…),色,B/BF,ラインスタイル`
`CIRCLE (x,y),半径,色,開始角,終了角,比率,F` `PAINT (x,y),塗り色,境界色` `POINT(x,y)`
`GET@(x1,y1)-(x2,y2),配列` `PUT@(x,y),配列,PSET/PRESET/XOR/OR/AND`
`VIEW` `WINDOW` `COLOR=(パレット,色)`（色は 0〜7 または &HGRB の 4096 色指定）

- `SCREEN 0/1`（200 ライン）は、400 ラインの画面に縦 2 倍で描きます。
- `SCREEN` の 4 番目（表示画面）はビットで指定します。1 でページ 0、2 でページ 1 を表示、0 でグラフィックを表示しません。定番の `SCREEN 3,0,0,1` はページ 0 に描いてページ 0 を表示します。
- `COLOR` の 5 番目（カラーモード）は受け付けますが、P9PBASIC は常に 16 色モードで動きます。パレット 0〜7 は 8 色モードと同じ色なので、見た目は変わりません。
- `STEP` による相対座標が使えます。

### ファイル
`OPEN "名前" FOR INPUT/OUTPUT/APPEND AS #n`（旧形式 `OPEN "I",#1,"名前"` も可）
`CLOSE` `PRINT #` `PRINT # USING` `WRITE #` `INPUT #` `LINE INPUT #` `EOF()` `LOF()` `LOC()`
`FILES` `KILL` `NAME〜AS` `BSAVE` `BLOAD` `DSKF()`

### ハードウェア直接操作
`INP(ポート)` `OUT ポート,値` `WAIT ポート,AND値,XOR値` `PEEK` `POKE` `DEF SEG`
`VARPTR(変数)`（オフセット）`VARPTR(変数,1)`（セグメント）`CALL アドレス変数`

### 関数
`ABS ASC ATN CDBL CHR$ CINT COS CSNG CSRLIN CVI CVS CVD EOF EXP FIX FRE HEX$ INKEY$ INP INPUT$
INSTR INT LEFT$ LEN LOC LOF LOG MID$ MKI$ MKS$ MKD$ OCT$ PEEK POINT POS RIGHT$ RND SGN SIN
SPACE$ SPC SQR STR$ STRING$ TAB TAN VAL VARPTR STICK STRIG TIME$ DATE$ ERR ERL
KLEN KMID$ KINSTR KTYPE KNJ$ JIS$`

- `MKS$` `MKD$` `CVS` `CVD` は N88-BASIC と同じ **MBF 形式**なので、N88-BASIC で作ったデータファイルと互換です。

## 第三章 キー入力と I/O の扱い

P9PBASIC は起動時にキーボード割り込み（IRQ1 = INT 09h）を自前のルーチンに差し替え、
8251（ポート 41h）から直接スキャンコードを受け取っています。BIOS のキー入力ルーチンは通りません。

### INP(&H41) について
キーボードの 8251 はインタプリタ自身も読んでいるため、BASIC プログラムが実ポートを直接読むと取り合いになります。そこで 2 つの動作を用意しています。

| モード | 起動オプション | INP(&H41) の値 |
|---|---|---|
| 既定 | なし | 割り込みルーチンが最後に受け取ったスキャンコード（押すとコード、離すとコード+80h）。取りこぼしません |
| 実ポート直読み | `/R` | 本当にポート 41h を読みます（実機と同じく割り込みと取り合います） |

例：
```
10 S=INP(&H41)
20 IF S=&H3A THEN PRINT "↑を押した"
30 IF S=&HBA THEN PRINT "↑を離した"
40 GOTO 10
```

### キーマトリクス INP(&HE0)〜INP(&HEC)
N88-BASIC(86) と同じく、`INP(&HE0)`〜`INP(&HEC)` の 13 バイトでキーの押下状態を読めます。
各ビットは **離しているとき 1、押しているとき 0** です。同時押しの判定に使えます。
（この 13 バイトは実際の I/O ポートではなく、P9PBASIC のキー割り込みが作っている値です。`/R` を付けても変わりません。）

| ポート | bit7 | bit6 | bit5 | bit4 | bit3 | bit2 | bit1 | bit0 |
|---|---|---|---|---|---|---|---|---|
| E0h | テンキー7 | テンキー6 | テンキー5 | テンキー4 | テンキー3 | テンキー2 | テンキー1 | テンキー0 |
| E1h | RETURN | テンキー. | テンキー, | テンキー= | テンキー+ | テンキー* | テンキー9 | テンキー8 |
| E2h | G | F | E | D | C | B | A | @ |
| E3h | O | N | M | L | K | J | I | H |
| E4h | W | V | U | T | S | R | Q | P |
| E5h | - | ^ | ] | ¥ | [ | Z | Y | X |
| E6h | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
| E7h | _ | / | . | , | ; | : | 9 | 8 |
| E8h | CTRL | SHIFT | カナ | GRPH | DEL | → | ↑ | HOME/CLR |
| E9h | ESC | SPACE | f5 | f4 | f3 | f2 | f1 | STOP |
| EAh | CAPS | テンキー/ | テンキー- | COPY | HELP | ← | ↓ | TAB |
| EBh | ― | ― | ― | ― | ― | ― | ROLL DOWN | ROLL UP |
| ECh | INS | f10 | f9 | f8 | f7 | f6 | XFER | BS |

例：
```
10 IF INP(&HE9)=191 THEN PRINT "スペースが押されている"
20 IF (INP(&HE8) AND 2)=0 THEN PRINT "↑が押されている"
30 GOTO 10
```
- 押しっぱなしの間ずっと 0 のままなので、`INKEY$` と違いキーリピートの影響を受けません。
- CAPS・カナはロックキーなので、ロックしている間 0 になります。
- STOP は中断にも使われるため、プログラム実行中に押すとそのまま中断します。

### キー状態テーブル（PEEK）
割り込みルーチンは、PC-98 で昔から使われているキー状態テーブル **0000:052Ah〜0539h**（16 バイト）と、
シフト状態 **0000:053Ah** を毎回更新します。キーを押しっぱなしにしている間ビットが 1 になるので、同時押しの判定に使えます。

```
10 DEF SEG=0
20 IF PEEK(&H52A+7) AND 4 THEN PRINT "↑が押されている"   ' スキャンコード 3Ah → 7番目のバイトの bit2
30 GOTO 20
```

`STICK(0)` はカーソルキーとテンキーの 2・4・6・8 から方向（1〜8）を、`STRIG(0)` はスペースキーの状態を返します。

### その他のキー
- CAPS・カナはロックキーとして扱います。カナ入力は JIS かな配列です。GRPH キーによる文字入力には対応していません。
- ROLL UP / ROLL DOWN / HELP / COPY は無視します。

## 第四章 N88-BASIC(86) との違い・トラブルシューティング

### 違いと未対応の機能
- 中間言語形式の .BAS ファイルは読めません（ASCII 形式で保存し直してください）。
- ランダムファイル（`FIELD`、`GET #`、`PUT #`）は未対応です（「関数・命令の使い方が正しくありません」、エラー番号 5）。
- `PLAY` は何もしません。`SOUND` はビープ音の長さだけを再現します（音程は変わりません）。
- `LPRINT` と `LLIST` は何も出力しません。
- `WIDTH 80,20` / `WIDTH 40,20` は受け付けますが、画面は 25 行表示のまま上 20 行を使います。
- `PAINT` のタイルパターン、`DEF USR` と `USR`、`ON TIME$`、`ON STOP`、`ON COM`、通信系の命令は未対応です。
- `CALL` は引数を無視して `DEF SEG:アドレス` を far call します（機械語は RETF で戻ってください）。
- 倍精度は内部で IEEE 倍精度（仮数 53 ビット）で計算します。N88-BASIC（仮数 56 ビット）とは 16 桁目が違うことがあります。
- `FOR` の初期値が終値をすでに越えている場合、ループ本体は 1 回も実行されません。
- `VARPTR(変数)` はオフセットだけを返します。`POKE` で変数を書き換えるときは `DEF SEG=VARPTR(変数,1)` でセグメントを合わせてください。
- 予約語と変数名はスペースなどで区切ってください（N88-BASIC と同じく、英数字のひとかたまりを 1 語として読みます）。`OUTE` や `STOC` のように予約語を含む変数名はそのまま使えます。予約語の直後に数字が続く書き方（`GOTO100`、`TO9`）と `GO TO` は受け付けます。`FORI=1TO9` のように予約語と変数名をつなげて書くと文法エラーになります。
- 実行速度は本家の N88-BASIC(86) より遅めです（整数変数を使うと速くなります）。
- `FRE()` はプログラム領域の空きバイト数を返します。

- エラーメッセージは日本語で表示します（例：「文法が正しくありません（100行）」）。`ERR` で得られるエラー番号は N88-BASIC と同じなので、`ON ERROR` で番号を見て分岐するプログラムはそのまま動きます。
- `RND` の乱数列は独自の計算方法なので、同じ `RANDOMIZE` の値でも N88-BASIC とは違う並びになります。

### よくある症状
| 症状 | 原因と対処 |
|---|---|
| キーを押しても反応しない | 実行環境が IRQ1（INT 09h）と 8251 のポート 41h/43h を実装している必要があります。PC98PLAYER のキーボード処理がこれを満たしているか確認してください |
| BEEP の長さがおかしい | VSYNC 割り込み（IRQ2、ポート 64h）が無い環境では、GDC のステータス（ポート 60h の bit5）を読んで時間を数えます |
| グラフィックが表示されない | 16 色モード（ポート 6Ah）とアナログパレット（A8h〜AEh）を使います。PC-9801VM 以前の 8 色機では色が正しく出ないことがあります |
| 「ファイルのモードが正しくありません」で読めない | 中間言語形式のファイルです。ASCII 形式で保存し直してください |
| 「メモリが足りません」 | プログラム領域は約 64KB です。大きな配列は分けて確保してください |

### 使用しているハードウェア
テキスト VRAM（A000h/A200h）、テキスト GDC（60h/62h：カーソルのみ）、モードフリップフロップ（68h、6Ah）、
キーボード 8251（41h/43h、IRQ1）、VSYNC（64h、IRQ2）、割り込みコントローラ（00h/02h）、ビープ（37h）、
グラフィック VRAM（A800h/B000h/B800h/E000h）、グラフィック GDC（A2h：表示の開始・停止）、
バンク切替（A4h/A6h）、パレット（A8h〜AEh）。

## 第五章 独自実装について
P9PBASIC は、N88日本語BASIC(86) の ROM・実行ファイル・逆アセンブルリストを一切使わずに、C 言語で新規に書いたものです。
互換性は、公開されている言語仕様（命令の書式と動作）と PC-98 のハードウェア仕様だけを手がかりにしています。

- 内部の中間コード（キーワードの番号、数値定数の目印）は独自の割り当てで、N88-BASIC の中間言語とは異なります（保存は常に ASCII 形式なので、互換性には影響しません）。
- 乱数の計算方法、エラーメッセージ、入力のやり直し表示、ファンクションキーの初期値、起動画面は独自のものです。
- 同じにしているのは、互換性のために必要な部分だけです：命令・関数の名前と書式、エラー番号、数値の表示形式、`MKS$`/`MKD$` の MBF 形式、`BSAVE` ファイルの先頭 7 バイトの形式、プロンプトの `Ok`。

## 付録 同梱サンプル
- `HELLO.BAS` … 漢字表示と INPUT の例
- `DEMO.BAS` … グラフィック命令（LINE / CIRCLE / PAINT）のデモ
- `KEYDEMO.BAS` … INKEY$、INP(&H41)、キーマトリクス INP(&HE0)〜INP(&HEC)、キー状態テーブル、STICK(0) の表示（ESC で終了）
